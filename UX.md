Primary user journey:
sign in
start new analysis
choose exercise
record or upload clip
watch upload/processing state
view results
revisit session history
Screen-level UX plan:
Auth screens adapted from old-proj
Home/session dashboard
New analysis screen
Processing/status screen
Results screen
Settings/profile screen
Results screen requirements:
summary score cards
top findings
flagged timeline moments
annotated frames or replay artifact
charts for timing, symmetry, stroke height, drift
short concrete suggestions
UX honesty rules:
frame output as motion analysis, not expert diagnosis
show confidence/limitations where signal is weak
avoid vague coaching copy
Visual conventions:
reuse useColors, ThemeContext, useResponsiveStyles, and shared common components
keep mobile screens dense, readable, and task-focused
avoid marketing-style landing pages
